# HealthCoach V0.1

Application Android personnelle de tableau de bord Santé Connect.

- Lecture locale uniquement de Santé Connect.
- Sommeil, FC repos, VFC, respiration, pas.
- Références personnelles sur les 30 derniers jours disponibles.
- Score de récupération local simple et explicable.
- Partage d'un résumé structuré vers ChatGPT via la feuille de partage Android.

Aucune donnée n'est envoyée automatiquement sur Internet dans cette V0.1.
