# MegaMobile

Dépôt public utilisé pour le jeu mobile **MegaMobile** et son système de mise à jour automatique.

## Fonctionnement
- L'application Android reste installée sur le téléphone.
- À chaque lancement, elle charge la dernière version publiée ici.
- Les mises à jour de gameplay peuvent être publiées sans réinstaller l'application.
- Une nouvelle APK n'est nécessaire que pour les changements du lanceur Android.

Le dossier `live/` contient la version actuellement distribuée.
